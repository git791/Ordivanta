# Ordivanta Skills

These skill files are reusable task playbooks for people or coding agents working on this repository.

- `scheduling-model/SKILL.md` — MILP, Greedy, constraint correctness and validation.
- `api-engineering/SKILL.md` — FastAPI schemas, routes, errors and integration tests.
- `frontend-design/SKILL.md` — industrial UI, accessible workflows and frontend quality.

They describe expected working practices; they do not imply that the associated features are already implemented.
